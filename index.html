Notation Key - what the numbers mean

+N st = semitone distance+7 st means seven semitones above the current reference note. “st” always means semitones.
1, 2, ♭3, 4, 5… = scale degrees5 means the fifth degree of the scale - not “five semitones.”
m3 / M3 / P5 = interval namesP5 means perfect fifth. From a root, a P5 is +7 st.
+12 st = octave repeatAdd or subtract 12 semitones to keep the same pitch class / scale degree in another octave.
NO BARE +5
This book now writes the unit or the function. A power chord is degrees 1-5, also written R + P5, which equals 0 and +7 st. “+5” by itself is ambiguous because +5 semitones is actually a perfect fourth.

The Octave Continuation Rule

A scale formula is not a finite list of allowed notes. It is a repeating pitch-class pattern. Every 12 semitones, the same scale degrees return in a new octave.

IdeaB natural minor example
One-octave formula0 2 3 5 7 8 10 [12]
Next octave12 14 15 17 19 20 22 [24]
Below the root... -12 -10 -9 -7 -5 -4 -2 0
Ruleadd or subtract 12; the scale degree stays the same
MODULO-12 RULE
If a distance is outside one octave, wrap it by 12. Example: +15 st -> 15 mod 12 = 3, so it is still the ♭3, one octave higher.
WHY THIS MATTERS
Guitar frets above 12, bass lines below the chosen root octave, MIDI notes, and vocal runs can keep moving without ever "running out" of scale.
TRY
On a B string, play B natural minor at 0-2-3-5-7-8-10-12, then continue 14-15-17-19-20-22-24. Same scale, higher register.

Tonic: The Feeling of Home

A tonal center is the pitch the music makes feel like home. A scale pattern alone does not guarantee a mode - the listener has to hear the intended tonic.

KNOW
The first note, lowest note and most common note can suggest the tonic, but none of them automatically determines it.
TRY
Loop B-C-D-E-F#-G-A while repeatedly returning to B. Then use the same notes but make D feel like the resting point. Same pitch collection, different tonal center.

Finding the Key

  1. Find the note/chord that feels most resolved.
  2. List the repeated or emphasized pitches.
  3. Check the chords under the melody.
  4. Test likely scale formulas against the evidence.
  5. Confirm by listening for resolution, not by trusting a single note.
WATCH OUT
One sung D does not mean the song is in D. D belongs to many keys and modes.

Chord Tones vs Scale Tones

A scale tells you the available pitch vocabulary. The current chord tells you which notes feel most stable right now.

Over BmRole
B (1)root - strongest home
D (♭3)minor-defining chord tone
F# (5)stable fifth
C#, E, G, Ascale colors/tensions whose effect depends on placement and resolution
VOCALS
When a melody feels like it wanders, aim phrase endings at chord tones first. Use the other scale notes to travel between them.
WATCH OUT
"It is in the scale" does not mean "it is equally stable over every chord."

Universal Fretboard Logic

Every fret raises a string by one semitone. Tuning changes where the notes live, not the theory underneath them.

RuleMeaning
fret nopen-string pitch + n st (one fret = one semitone)
12th fretsame pitch class, one octave higher
R + P5+7 st from the root = perfect fifth
R + octave+12 st = same pitch class one octave higher
scale overlayshow only pitch classes belonging to the chosen scale
CORE MODEL
Learn interval relationships first; treat each tuning as a coordinate system for the same music.
TRANSFER
A 1-♭2-♭3 Phrygian idea stays 1-♭2-♭3 whether the low string is B, C or A. Only the fret/note locations change.
SPELLING NOTE
Fretboard diagrams use one consistent sharp-based chromatic label set for compact visual lookup. In harmonic analysis, use the correct enharmonic spelling for the key/interval (for example Eb rather than D# in C minor).

Guitar Survival Sheet

Need scale notes?

Root + scale semitone formula

Add/subtract 12 st to repeat the same scale degrees in other octaves.

Need a power chord?

Degrees 1 + 5 · intervals R + P5

Distance: 0 st + 7 st. In B: B + F#. Optional octave: +12 st.

Need darker?

Emphasize ♭2

♭2 sits +1 st above the tonic. In B: B → C. Phrygian makes this relationship structural.

Need minor character?

♭3 defines minor

Then ♭6 and ♭7 can deepen natural-minor color. In B: D, G and A.

Need more range?

Octave displacement = ±12 st

Move an idea into another register before assuming you need an even lower tuning.

Drop A getting muddy?

Separate register + role

Simplify low guitar layers; let bass, kick and sub each earn their space.

Changed tuning?

Open pitch + fret number = pitch

The shapes may change. Semitone and interval logic does not.

Reading shorthand

5 ≠ +5 st ≠ P5

5 = degree five. +5 st = perfect fourth distance. P5 = perfect fifth = +7 st.

GOLD-SEAL RULEShapes are conveniences. Intervals are the truth.

What Is a Vocal Run?

A run is a rapid melodic movement through multiple pitches. "Melisma" describes multiple notes sung on one syllable; a melisma can contain a run.

TypeDefinition

Pentatonicuses a five-note pentatonic set

Chromaticincludes semitone motion outside the base scale

Common Misconceptions

  • "The song starts on D, so it is in D." Starting note is evidence, not proof of tonic.
  • "A note outside the scale is wrong." Chromatic and borrowed notes can be intentional.
  • "Everything in the scale sounds equally good over every chord." Chord context changes stability.
  • "A third above means +3 semitones." Diatonic thirds vary between 3 and 4 semitones.
  • "Modes are just patterns." Tonal center is part of modal identity.
  • "Bass should follow guitar." That is one role, not the definition of bass.
  • "A pitch detector can name every scream." Noise-dominant harsh vocals may not have one reliable fundamental.

This manual uses standard 12-tone equal-temperament interval/chord terminology and presents practical descriptions rather than claiming that scales have fixed emotional meanings.
